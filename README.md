# ҰБТ жолы: Химия – Биология

Қарындасқа арналған ҰБТ-ға дайындық сайты. Қазіргі нұсқа: бір файлдан тұратын статикалық бет (кері санақ, прогресс, пәндер графигі, тақырыптар тізімі). Келесі кезең: кіру жүйесі бар жеке сайт және RAG негізіндегі ИИ-көмекші.

## 1. Қазіргі күйі

- Бір файл: `index.html` (HTML, CSS, JavaScript бір жерде, сыртқы кітапханасыз).
- Сыртқы тек Google Fonts (Noto Serif, Noto Sans).
- Деректер браузердің `localStorage` ішінде сақталады: күндер, есім, пәндердің қазіргі баллы, тақырып белгілері. Серверсіз, құрылғыдан құрылғыға көшпейді.
- Деплой: GitHub Pages (`main` тармағы, `/ (root)`).

### Бетте не бар

| Бөлім | Сипаттама |
|---|---|
| Жоғарғы жазба | Мотивациялық сөйлемдер, басқанда келесісі шығады. `{name}` есіммен ауысады |
| Кері санақ | Қаңтар ҰБТ, наурыз ҰБТ, негізгі ҰБТ: күн, сағат, минут, секунд |
| Жол | pH шкаласы: бастау 50, медицина шегі 70, мақсат 125, арман 130 |
| Пәндер графигі | Әр пән үшін жоспар сызығы және қазіргі балл |
| Тақырыптар | 5 пән, 51 тақырып, белгі қоятын тізім |
| Баптау | Күндер, есім, қазіргі баллдар, жазбалар |

## 2. Деректерді өзгерту

`index.html` ішіндегі скрипттің басында:

- `DEF` — бастапқы мәндер (есім, жазбалар, ҰБТ күндері, қазіргі баллдар).
- `SUB` — пәндер массиві: `max` (максимум), `st` (бастау), `go` (мақсат), `pl` (5 нүктелі жоспар: қазір, желтоқсан, наурыз, сәуір, негізгі ҰБТ), `tp` (тақырыптар).
- ҰБТ күндері шамамен қойылған (10 қаңтар, 10 наурыз, 10 мамыр 2027). Нақты күндерді Ұлттық тестілеу орталығы сайтынан тексер.
- `localStorage` кілті `ubt-v1`. Құрылымды өзгертсең, кілтті `ubt-v2` деп ауыстыр, ескі сақталған деректермен қайшылық болмайды.

## 3. GitHub Pages арқылы жариялау

1. Репозиторий жаса (ұсыныс: `ubt-path`, Public).
2. `index.html` файлын жүкте (**Add file → Upload files**).
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. 1–2 минуттан кейін сайт `https://ЛОГИН.github.io/ubt-path/` адресінде ашылады.
5. Жаңарту: жаңа `index.html` жүктесең болды.

Ескерту: тегін GitHub Pages сайты ашық, сілтемесі бар кез келген адам көре алады. Құпия мәліметтерді (парольдер, API кілттері) бұл репозиторийге ешқашан салма.

## 4. Келесі кезең: кіру жүйесі + RAG

Мақсат: қарындас жеке аккаунтпен кіріп, дайындалатын, ИИ-көмекшіге тақырып бойынша сұрақ қоятын сайт.

### 4.1. Ұсынылатын стек

| Қабат | Таңдау | Себебі |
|---|---|---|
| Фронтенд және сервер | Next.js (React) | Бет те, API де бір жобада |
| Кіру жүйесі | Supabase Auth (немесе Firebase) | Дайын авторизация, парольді өзіміз жазбаймыз |
| Дерекқор | Supabase Postgres | Баллдар, белгілер, чат тарихы |
| Векторлық іздеу | Supabase `pgvector` | Дерекқормен бірге, қосымша қызмет керек емес |
| ИИ | Claude API (сервер арқылы) | Жауап генерациясы. Қолданыстағы модельдерді docs.claude.com-нан тексер |
| Embedding | Көп тілді модель (мысалы, Voyage AI немесе `multilingual-e5`) | Қазақ тіліндегі сапасын міндетті түрде өлше |
| Хостинг | Vercel | Next.js үшін ыңғайлы |

### 4.2. Қауіпсіздік

- Өзіндік тіркелуді өшір. Аккаунтты қолмен бір рет жаса.
- API кілтін тек сервердің орта айнымалыларында (environment variables) сақта, фронтендке қоспа.
- Сұраныс лимитін және ай сайынғы шығын лимитін қой.
- Supabase-те әр кесте үшін Row Level Security қос: пайдаланушы тек өз жолдарын көреді.
- Тек қажетті деректерді сақта: баллдар, тақырып белгілері, чат тарихы. Қарындас кәмелетке толмаған болуы мүмкін, сондықтан артық жеке дерек жинама.

### 4.3. RAG архитектурасы

```
Материалдар → бөлшектеу (chunk) → embedding → векторлық база
                                                   ↑
Сұрақ → embedding → ең жақын k үзінді → Claude (үзінділермен) → жауап + дереккөз
```

**Білім базасына не салуға болады**
- Өз конспектілерің және мұғалім материалдары (рұқсатымен).
- Лицензиясы ашық немесе авторлық құқығы өзіңде болатын оқу материалдары.
- Ресми ҰТО спецификациясының тақырыптар тізімі (құрылымды құру үшін).
- Нақты ҰБТ тестілерінің сұрақтарын және авторлық құқығы қорғалған оқулықтарды рұқсатсыз салма.

**Бөлшектеу ережелері**
- Әр бөлшек бір тақырып шеңберінде болсын (мысалы, «Митоз және мейоз»), шамамен 300–600 сөз.
- Метадеректер: пән, тақырып (`SUB.tp` тізіміндегі бірдей атау), дереккөз, бет.
- Тақырып атаулары осы жобадағы `SUB` массивімен бірдей болсын, сонда прогресс пен іздеу байланысады.

**Жауап беру ережелері (жүйелік нұсқау)**
- Тек табылған үзінділерге сүйен, жауап жоқ болса, «базада жоқ» деп айт.
- Қазақ тілінде, қадамдап түсіндір, әр жауапқа дереккөзді көрсет.
- Есептерде шешімді қадамдап көрсет. Есептеу қателері болуы мүмкін, күдікті жерді оқулықпен тексер.
- Сынақ тапсырмаларын тақырып бойынша өзің құрастыр, ҰТО сұрақтарын көшірме.

**Сапаны бағалау**
- 30–50 сұрақтан тұратын тексеру жинағын құр (сұрақ, дұрыс жауап, күтілетін тақырып).
- Әр өзгерістен кейін іздеудің дәлдігін (дұрыс бөлшек табылды ма) және жауап сапасын тексер.

### 4.4. Мүмкіндіктер тізімі

1. Кіру жүйесі және жеке профиль.
2. Сынақ тест журналы: балдар, графиктер (қазіргі `SUB` деректері көшіріледі).
3. Тақырып белгілері дерекқорда (құрылғыдан тәуелсіз).
4. RAG-репетитор: тақырып бойынша сұрақ-жауап, дереккөзбен.
5. Қателер журналы және әлсіз тақырыптарды анықтау.
6. Әлсіз тақырып бойынша жеке тапсырмалар генерациясы.
7. Апталық жоспар (әлсіз тақырыптарға қарай автоматты түзетіледі).

### 4.5. Бір айлық жоспар

| Апта | Міндет |
|---|---|
| 1 | Next.js жобасы, Supabase Auth, дерекқор кестелері, қазіргі дизайнды көшіру |
| 2 | Сынақ тест журналы, графиктер, тақырып белгілері дерекқорда |
| 3 | Материалдарды жинау, бөлшектеу, embedding, векторлық іздеу, алғашқы RAG жауаптары |
| 4 | Тексеру жинағы, сапаны жақсарту, қателер журналы, тапсырма генерациясы, Vercel-ге деплой |
